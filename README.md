# 🧺 LaundryKu

Sistem Informasi Kasir Laundry Desktop menggunakan Java NetBeans dan MySQL.

## 📌 Tentang Project

LaundryKu merupakan aplikasi desktop sederhana yang dibuat untuk membantu proses pengelolaan usaha laundry. Aplikasi ini dikembangkan menggunakan Java Swing pada NetBeans dan database MySQL.

Project ini dibuat sebagai tugas kuliah dengan konsep CRUD (Create, Read, Update, Delete) yang sederhana dan mudah dipahami.

---

## 🚀 Fitur

- 🔐 Login Admin
- 🏠 Dashboard
- 👤 Data Pelanggan
- 🧺 Data Jenis Laundry
- 💳 Data Transaksi
- 🔗 Koneksi Database MySQL

## ⚙️ Cara Menjalankan

1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Import database `laundryku`.
4. Buka project menggunakan NetBeans.
5. Tambahkan MySQL Connector ke Libraries.
6. Jalankan project.
7. Login menggunakan akun admin.
